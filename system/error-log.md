# Error Log｜錯誤追蹤

錯誤紀錄由各筆 `LearningEvent` 的 `corrections` 與答錯 `items` 生成，不另維護容易與課程紀錄不一致的第二份檔案。每次批改應先區分口誤或偶發筆誤，再判斷是否值得追蹤；影響理解、重複出現或對應本課重點的錯誤應收錄。

## 十類錯誤

| 類別 | 判斷例子 |
| --- | --- |
| Vocabulary | 選錯詞或誤解詞義 |
| Grammar | 時態、語氣或句構使用不合語境 |
| Verb Conjugation | 人稱、數、時態的動詞形式錯誤 |
| Gender | 名詞／形容詞陰陽性不一致 |
| Articles | 冠詞缺漏或選錯 |
| Prepositions | 介系詞搭配錯誤 |
| Word Order | 語序妨礙自然表達或理解 |
| Pronunciation | 有音訊證據的發音或重音問題 |
| Spelling | 拼字、重音符號或標點問題 |
| Natural Expression | 可理解且合文法，但母語者通常不用的搭配 |

每項顯示：語言、類別、原句、修正、原因、較自然說法（適用時）、首次與最近發生日、次數、目前狀態（觀察中／需補強／已改善）。以「語言＋類別＋相同結構」歸併反覆錯誤，不能只按字面完全相同才計數。教師須維持原句、修正、原因的逐句格式。若義文錯誤源於西文規則，解釋需寫明「你原本可能受到西班牙文影響」，再說明義文規則。

同一結構於至少兩次工作階段累積三次錯誤，標為「需補強」，下一課先插入少量針對性練習；連續兩次相關練習正確後標為「已改善」，仍遵守一般複習排程。不得只為增加錯誤數而反覆考相同題。
