# Lesson X｜固定授課模板

授課前讀取目前階段、到期複習、最近兩次表現與需補強的 Error Log。每次先提供以下完整教材，再安排練習；除了口說／對話模式，不逐題等待回答。不要在西文 B1 通過前產生正式義文課。

## 1. Today’s Goals

以「今天完成後，我能……」列出 3–5 個可實際觀察的能力。每項要能由本課輸入或輸出題驗證。

## 2. Vocabulary

選 8–15 個核心詞。每詞列目標語、繁體中文意思、詞性、必要時的發音提示及一個自然例句。避免只給孤立單字或一次引入過多新詞。

## 3. Grammar

用繁體中文解釋本課一項主要文法及其使用邏輯：何時使用、簡單例句、常見錯誤與修正。若需要第二個重點，須直接服務本課任務。

## 4. Useful Patterns

列出 3–8 個真實日常會用的句型，附簡單實例。初期可有繁體中文提示，但鼓勵直接從情境理解。

## 5. Input

提供符合目前 CEFR 程度的目標語短文或對話。首次呈現不附中文翻譯；可提供情境及少量必要背景。若為聽力，另給自然 TTS 文本，先播放再顯示逐字稿。

## 6. Comprehension

理解問題由擷取資訊、關係推斷到簡短解釋，先不提供答案。音訊題須含真正的只聽理解與聽後重述，不能只讓學習者讀逐字稿。

## 7. Speaking

要求學習者使用本課內容自行造句或完成一個情境任務，不先給標準答案。口說／對話模式可逐輪追問；盡量維持目標語，必要時用繁體中文補教。

## 8. Writing

要求按程度寫 3–8 句起的目標語；A2/B1 可提高到有連接詞的短文。題目與今天的能力目標直接相關。

## 9. Error Correction

學習者回答後逐句呈現：

> 原句：
>
> 修正：
>
> 原因：

若原句合文法但不自然，另列「更自然：」。義文若受西文影響，說明「你原本可能受到西班牙文影響」，再解釋正確義文規則。反覆且有教學價值的錯誤，賦予 `error_key` 並放進紀錄包。

## 10. Review

在不直接給答案的情況下，請學習者回想今天的詞、文法及句型。將重要詞彙、句型、文法用穩定 ID 加入複習卡；答錯項隔日重現。課後回傳 [LearningEvent v1](learning-record.md) JSON 供網站同步。
