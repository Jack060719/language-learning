# 間隔複習與難度調整

重要詞彙、句型、文法以穩定項目 ID 建卡，每張卡保存初學日、最近複習日、熟練階段、曾否答錯及常犯錯誤。提示應要求回想或在情境中使用，不直接展示答案。新詞盡量放進句子。

## 排程

正常成功路徑的目標節點為 Day 0、1、3、7、14、30、60。第一次接觸立即做 Day 0 回想；成功後下一次間隔依序為 1、2、4、7、16、30 天。若實際複習延後，下一個間隔由**實際成功日**起算，不倒填到期日。Day 60 節點成功後標為熟練並停止固定重複；週測驗可以抽樣驗證。

答錯時記錄 `ever_wrong`、次數與錯誤類別，當次稍後重試一次，下一次排在隔日，熟練階段回到起點。再次成功才重新往後推。到期時間以台灣本地日判斷，避免跨裝置時區差異。複習記錄若無真實作答，不能人工標為成功。

## 每次學習的選題

先取到期項，再取最近需補強的結構，最後才加入新內容。Daily Mode 先用約 5–10 分鐘複習；題量過大時分批，不以清空卡片數量為目標。最早到期項逾期超過七天，啟動 Review Mode 暫停新文法。若最近兩次課程練習正確率均至少 85% 且口說／寫作任務達標，下一課只增加少量自由輸出；若最近兩次均低於 60%，先降難度與補教。特定錯誤跨兩次工作階段達三次，安排專項補強。

每課結束請學習者不看答案回想本課詞彙、文法與句型。錯誤重現時修正練習；已熟練項目不無限制循環。
