# 義大利文課程地圖｜0 → B1

本地圖供西班牙文 B1 關卡通過後使用。義文以標準義大利語為主；既有西文知識可作比較線索，不能直接當義文規則。每單元均含 Vocabulary、Grammar、Pronunciation、Listening、Reading、Speaking、Writing、Conversation、Review、Assessment，另有 **Spanish Interference** 提醒。

## 西文 → 義文橋接（Phase 5 起點）

| 主題 | 對照與教學重點 |
| --- | --- |
| 相似詞與拼字 | `familia/famiglia`、`quiero/voglio`；外形相似仍要重新學義文拼寫和語音。 |
| 發音 | 義文雙子音、`gli`、`gn`、`c/g` 與西文 `ll`、`ñ`、`j` 不等同。 |
| 動詞與句型 | `ser/estar` 不等於義文 `essere/stare` 的完整用法；`tener` 不可直接套為 `tenere`，義文常用 `avere`。 |
| 名詞與功能詞 | 比較性別、冠詞 `il/lo/la/l'`、介系詞與合併冠詞；每個詞按義文實際用法學。 |
| 假朋友 | 例如西文 `burro` 是驢，義文 `burro` 是奶油；以句子驗證意思。 |

橋接以辨認及修正混用為目的，不替代義文 A1。批改時若出現西文遷移，固定補上「你原本可能受到西班牙文影響」及義文真正用法。

## 0 → A1｜熟悉情境中的基本交流

**學習目標：** 能清楚發音、介紹自己與他人、談家人和日常、處理點餐購物及簡單問路。

| 單元 | 核心詞彙與情境 | 核心文法、發音 | 必備句型與產出；Spanish Interference |
| --- | --- | --- | --- |
| A1-01 聲音與問候 | 問候、姓名、出身 | 母音、雙子音、`c/g`；`essere`、`chiamarsi` | `Mi chiamo…`；不要寫成西文 `Me llamo` |
| A1-02 家人與身分 | 家人、國籍、職業 | 名詞性別、`il/lo/la/l'`、形容詞一致 | `Questa è mia sorella.`；冠詞不照搬西文 |
| A1-03 數字與時間 | 年齡、日期、時間、價格 | `avere`、疑問詞、`gn/gli` | `Ho … anni.`；不說 `Sono … anni` |
| A1-04 每日生活 | 起居、課堂、工作 | 現在式規則動詞、常用不規則動詞 | `Studio la mattina.`；動詞字尾重新學 |
| A1-05 咖啡廳與超市 | 飲食、數量、喜好 | `volere`／`potere`、`mi piace` | `Vorrei un caffè.`；不套西文 `quiero` |
| A1-06 家與城市 | 房間、地點、交通 | `c'è/ci sono`、`stare` 基礎、介系詞 | `C'è una stazione qui.`；勿把 `hay` 套過來 |
| A1-07 休閒與安排 | 興趣、天氣、週末 | 反身動詞入門、`andare`、常用將來表達 | `Domani vado a…`；注意 `a/in` 用法 |
| A1-08 整合與關卡準備 | 前述日常詞彙 | 現在式、冠詞、地點整合 | 自介、點餐、購物、問路、短訊 |

**Vocabulary：** 每課 8–15 個詞配自然義文例句，先學最常用生活詞。**Grammar：** 義文名詞、冠詞、現在式及基本地點句。**Pronunciation：** 雙子音、`gn/gli`、`c/g`、清晰重音。**Listening：** 聽懂慢速清楚的個人資訊、價格和簡短問答。**Reading：** 讀懂告示、菜單和短訊。**Speaking／Conversation：** 以短句完成自介及服務情境。**Writing：** 寫 3–8 句生活句。**Review：** 每課穿插義文舊內容與西義混淆辨識。**Assessment：** 測自介、日常交換、短文、音訊與短句寫作；五技能過關後才進 A2。

## A1 → A2｜熟悉生活任務、經驗與計畫

**學習目標：** 能處理旅行、學習和健康情境，描述已發生事件、過去習慣與近期計畫，進行簡單對話。

| 單元 | 核心詞彙與情境 | 核心文法、發音 | 必備句型與產出；Spanish Interference |
| --- | --- | --- | --- |
| A2-01 旅程與交通 | 車站、住宿、移動 | `passato prossimo`＋`avere` | `Ho visitato Roma.`；勿套單一西文過去式 |
| A2-02 行動與經驗 | 出入、抵達、活動 | `passato prossimo`＋`essere`、分詞一致 | `Sono andata…`；助動詞不可一律用 `avere` |
| A2-03 過去習慣 | 童年、家庭、舊日常 | `imperfetto` 與已完成事件對比 | `Da piccolo/a giocavo…`；按義文語境選時態 |
| A2-04 健康與請求 | 症狀、藥局、預約 | 直接／間接受詞代詞入門、禮貌請求 | `Mi fa male…`；代詞位置重學 |
| A2-05 工作與學習 | 學校、任務、能力 | `dovere`、常用命令式、合併介系詞 | `Devo studiare.`；`di/a/in` 不照西文對應 |
| A2-06 計畫與比較 | 邀約、旅行、選擇 | 簡單未來式、比較級 | `Andrò… perché…`；動詞詞尾不同 |
| A2-07 意見與社交 | 朋友、運動、文化 | `penso che` 常見陳述、原因連接詞 | `Preferisco… perché…`；自然搭配需驗證 |
| A2-08 整合與關卡準備 | 日常、旅行、工作舊詞 | 過去時、助動詞、介系詞回顧 | 短敘事、計畫、對話與短文 |

**Vocabulary：** 旅行、健康、工作、學習、興趣及感受。**Grammar：** 複合過去式的助動詞選擇、`imperfetto`、代詞、合併介系詞與未來計畫。**Pronunciation：** 語流中的雙子音與重音辨識。**Listening：** 聽懂清楚的生活對話及短公告主旨。**Reading：** 讀懂短文章、電郵和行程。**Speaking／Conversation：** 談經驗、計畫、偏好及日常問題。**Writing：** 寫短敘事和簡單意見。**Review：** 混合 A1 弱點，尤其助動詞與冠詞。**Assessment：** 測過去經驗、未來計畫、敘事、意見及五技能。

## A2 → B1｜連續表達與熟悉議題的討論

**學習目標：** 能理解熟悉議題清楚標準語，敘述經驗、解釋原因、比較選擇並在旅行、學校或工作情境持續交流。

| 單元 | 核心詞彙與情境 | 核心文法、發音 | 必備句型與產出；Spanish Interference |
| --- | --- | --- | --- |
| B1-01 故事與背景 | 旅行、轉折、情緒 | `passato prossimo`／`imperfetto` 整合 | `Mentre… è successo…`；不可照西文形式套用 |
| B1-02 服務與問題 | 住宿、投訴、解法 | 關係代詞 `che/cui`、因果連接詞 | `Il problema è che…`；注意義文介系詞 |
| B1-03 工作與方向 | 專案、能力、目標 | 未來式與條件式常見用法 | `Vorrei…`、`Potrei…`；動詞變化重學 |
| B1-04 健康與建議 | 習慣、壓力、建議 | 常用 `congiuntivo`：必要、願望、看法 | `È importante che…`；語氣用途比照但形式不同 |
| B1-05 社會與媒體 | 新聞、文化、環境 | 觀點連接詞及段落組織 | `Da un lato… dall'altro…`；勿混用西文連接詞 |
| B1-06 科技與資料 | 工具、資料、結果、隱私 | `si` 無人稱常見讀法、比較與條件 | `Si usa per…`；`per/por` 不直接對應 |
| B1-07 深入對話 | 興趣、旅行、工作 | 澄清、追問、轉述；語調與流利度 | `Puoi spiegare meglio?`；維持義文對話 |
| B1-08 整合與關卡準備 | 熟悉的一般主題 | 時態、語氣及連接詞回顧 | 10–15 分鐘討論、一般文章、完整短文 |

**Vocabulary：** 工作、教育、旅行、新聞、科技與個人興趣，重視可用於說明和比較的詞。**Grammar：** 過去敘事、條件式、常見虛擬式與連接手段。**Pronunciation：** 在清楚標準語速下抓主旨，以重音和雙子音維持可理解度。**Listening：** 理解熟悉議題主要內容。**Reading：** 理解一般文章的觀點與理由。**Speaking／Conversation：** 描述經驗、比較選擇並維持 10–15 分鐘對話。**Writing：** 寫有段落的經驗或意見文章。**Review：** 針對反覆的 Spanish Interference 安排補強。**Assessment：** 五技能加長對話及完整文章，達標才標記義文 B1。
